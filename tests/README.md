# Manual OpenCADStudio smoke test
1. Build and install the plugin with `plugin.toml`.
2. Confirm one `Land Arch Tools` ribbon tab appears.
3. Confirm ribbon groups include Planting plus Materials / Furnishings / Amenities.
4. Run all catalog commands.
5. Place tree, shrub, planting area, grid, and naturalized planting.
6. Place material area and linear edge/wall.
7. Place furnishing and amenity.
8. Run plant/site/all schedules and QA/QC.
9. Save DWG, close, reopen, and verify LANDARCH XDATA survives.
10. Re-run schedules after reopen.
